Employee Offboarding Checklist

Close every door when someone leaves, and leave proof it happened. Built for SMBs and regulated institutions.

Version 1.0 · Last updated November 5, 2026

Departure details

For a termination, disable the primary account during the conversation, not after it. For an elevated user (admin, finance, or access to customer data), treat every step as same-day and have a second person witness it.

1. Trigger & scope

  • HR notice of departure has automatically opened this offboarding task (not word of mouth).
  • Cutoff time scheduled for the last working hour (planned exit) or set to immediate (termination).
  • Master list of access-granting systems pulled and attached to this record.

2. Directory & core accounts (IT)

  • Primary network / directory account disabled.
  • Email account disabled; auto-reply or redirect set per policy.
  • Mail forwarding checked and removed (common way departing staff keep seeing internal traffic).
  • Remote access (VPN) disabled; certificates and tokens on personal devices revoked.
  • Multi-factor enrollments removed.

3. Accounts outside the directory (IT + manager)

  • Standalone SaaS tools the team bought on their own closed or reassigned.
  • Banking, payroll, and finance portals access removed.
  • Domain registrar, DNS, and hosting logins reviewed.
  • Social media and marketing platform access removed.

4. Shared & service credentials

  • Any shared password the person knew has been rotated (disabling a named account does nothing here).
  • Wi-Fi key rotated if it was shared.
  • Shared mailbox / admin login credentials changed.
  • API keys and SSH keys the person generated revoked.

5. Physical & non-login access (facilities)

  • Building badge deactivated; alarm codes changed if known.
  • Company devices returned and wiped / re-imaged.
  • Mobile devices unenrolled from MDM.
  • Keys, tokens, and company cards collected.

6. Data handling & evidence

  • Mailbox and file retention handled per the decision made up front (not a last-minute judgment call).
  • Record shows who left, when access was removed, who removed it, and the systems covered.
  • Completed checklist filed with the exam / evidence folder.

Sign-off

Based on the article Employee Offboarding: Closing the Access Gap When People Leave. Pair it with a quarterly access review to catch anything a rushed exit missed.
